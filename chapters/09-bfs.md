# 第 09 章 · BFS：一层一层扩展最少步数

**本章完成后：** 用队列求网格中的最少步数，理解首次到达为何最优。

**建议学习方式：** 分两次完成。第一次读推导并手算，第二次盖住代码独立实现、做题和复盘。复杂章节可增加课次，不必一次读完。

## 1. 状态是什么，边是什么

输入 h、w 和 h 行网格，`.` 可走，`#` 障碍。机器人从左上角到右下角，每次上下左右走一格，每一步代价都是 1。
1≤h,w≤500。输出最少步数；起终点被挡住或无法到达时输出 -1。
状态是所在格子 `(r,c)`，一次合法移动是一条边。目标是最少移动次数，不是找出任意路径。

## 2. 为什么一条路走到底不够

DFS 先找到的路线取决于方向尝试顺序，它可能绕很远。
BFS 先处理距离起点 0 步的状态，再处理 1 步、2 步……，所以首次到达目标时不会漏掉更短路线。
用队列保证先进先出：早发现的近处格子先扩展。

## 3. 用 queue 保存待处理状态

`queue<pair<int,int>> q` 是一个保存坐标对的队列。pair 的两个字段是 first、second。
`q.push({r,c})` 入队，`q.front()` 查看队首，`q.pop()` 移除队首；pop 本身不返回元素。
`auto [r,c]=q.front()` 是 C++17 结构化绑定，将坐标对拆成两个局部变量，然后再 pop。

dist[r][c]=-1 表示还没发现这个格子。发现邻居时立刻设置距离并入队，而不是等它出队后才标记。
这样同一个格子被其他邻居看到时会跳过，不会在队列中重复堆积。

## 4. 一层层观察距离

网格如下，中心是障碍：

```text
...
.#.
...
```

最终距离表为：

```text
0 1 2
1 # 3
2 3 4
```

起点 dist=0，因为站在起点不算移动。若当前格子距离为 d，那么新发现的邻居距离是 d+1。
当发现距离 2 的格子时，所有能更早产生距离 1 路线的格子已经按队列顺序处理过。

## 5. 首次发现正确性的核心

队列中的距离按非递减顺序处理。假如首次发现 v 得到 d+1，却还有长度≤d 的路径，那么该短路上的前驱应在更早的层被处理，并更早发现 v，产生矛盾。
因此每个格子第一次被赋值时，最少步数已经确定。
这个论证依赖每条边代价相同。存在一般非负权重时要看第 13 章 Dijkstra；不能只把本章的 +1 改成 +权重就继续依赖 FIFO 队列。

## 6. 代价和实现顺序

每个格子最多入队一次，每次检查四个方向，时间 O(hw)，距离数组和队列空间 O(hw)。
访问邻居前先检查边界，再访问 grid[nr][nc]，否则可能越界。
1×1 的空地答案是 0；被堵住的 1×1 答案是 -1。这能检查初始化是否忠实于题意。

## 完整 C++17 例题程序

独立源文件：[09-bfs.cpp](../examples/09-bfs.cpp)。输入输出约定见本章题目；程序针对题目保证的合法输入。

```cpp
#include <iostream>
#include <queue>
#include <string>
#include <utility>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int h, w;
    if (!(cin >> h >> w)) return 0;
    vector<string> grid(h);
    for (auto &row : grid) cin >> row;
    if (grid[0][0] == '#' || grid[h - 1][w - 1] == '#') {
        cout << -1 << '\n';
        return 0;
    }
    vector<vector<int>> dist(h, vector<int>(w, -1));
    queue<pair<int, int>> q;
    dist[0][0] = 0;
    q.push({0, 0});
    const int dr[4] = {-1, 0, 1, 0};
    const int dc[4] = {0, 1, 0, -1};
    while (!q.empty()) {
        auto [r, c] = q.front();
        q.pop();
        for (int k = 0; k < 4; ++k) {
            int nr = r + dr[k], nc = c + dc[k];
            if (nr < 0 || nr >= h || nc < 0 || nc >= w) continue;
            if (grid[nr][nc] == '#' || dist[nr][nc] != -1) continue;
            dist[nr][nc] = dist[r][c] + 1;
            q.push({nr, nc});
        }
    }
    cout << dist[h - 1][w - 1] << '\n';
}
```

### 样例输入

```text
3 3
...
.#.
...
```

### 样例输出

```text
4
```

## 分层练习：先独立做，再展开答案

1. 1×1 空地与 1×1 障碍各输出什么？
2. 如何在输出距离之外，还原一条最短路径？说明什么时候记录前驱。
3. 将起点改为多个救援站，求每个格子到最近救援站的距离，队列怎样初始化？

<details>
<summary>参考答案与思路（先尝试再看）</summary>

1. 0 和 -1。前者无需移动，后者起点不合法。
2. 首次发现邻居时记录 parent[nr][nc]=(r,c)。到终点后沿前驱回到起点，再反转顺序；不可达时不做回溯。
3. 将所有合法救援站距离设为 0 并同时入队，其他状态仍为 -1。这是多源 BFS，队列层次证明仍成立。

</details>
