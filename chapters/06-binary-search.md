# 第 06 章 · 二分查找：维护一个一定包含答案的范围

## 1. 找到第一个满足条件的位置

给定非递减数组 a，回答 q 次查询：第一个满足 a[i]≥x 的 0-based 下标是多少？没有则输出 n。
输入 n、q，接着 n 个数和 q 个查询值。0≤n,q≤200000，数值绝对值≤10^9。
例如 `[1,2,2,5]` 查询 2，应返回 1，而不是随便一个值等于 2 的位置。

## 2. 二分利用的到底是什么

对固定 x，判断 `a[i]≥x`，结果从左到右一定是若干 false，再接若干 true。
这来自数组有序。我们寻找的是两种结果之间的分界点。
若中间值已经≥x，答案可能在它左边，也可能就是它；若中间值<x，它和它左边的元素都不可能是答案。
一次比较排除整段候选位置，这才是二分比逐个扫描快的原因。

## 3. 明确区间约定，再写代码

初始化 l=0、r=n，尚未确定的真实元素位于半开区间 [l,r)。维护：

- 下标小于 l 的元素全部 <x。
- 下标大于等于 r 的真实元素全部 ≥x。
- 所求分界下标位于闭区间 [l,r]；n 是“找不到”的合法返回值。

取 `mid=l+(r-l)/2`。若 a[mid]≥x，令 r=mid；否则令 l=mid+1。
当 l<r 时 mid<n，所以只访问真实元素，不会访问 a[n]。
当 l=r 时，左侧全部不合格，右侧全部合格，l 就是所求边界。

## 4. 跟踪一次查询

数组 `[1,2,2,5]`，x=2：

| l | r | mid | a[mid] | 下一步 |
|---:|---:|---:|---:|---:|---|
| 0 | 4 | 2 | 2 | r=2，保留它和左侧 |
| 0 | 2 | 1 | 2 | r=1 |
| 0 | 1 | 0 | 1 | l=1 |

此时 l=r=1，结束。重复元素并不会破坏算法，因为我们找的是第一个 true。
若 x=6，最后 l=r=4；若数组为空，初始 l=r=0，循环直接跳过。

## 5. 复杂度和边界

每次把候选范围缩小约一半，一次查询 O(log(n+1))，n≥2 时通常简写 O(log n)。
整体 O(n+q log(n+1))，存储 O(n)。标准库 `lower_bound` 可以做同样的工作，手写版本帮助理解边界。
`upper_bound` 找第一个 >x 的位置；两者下标之差就是有序数组中 x 的出现次数。

## 6. 从查找数值到二分答案

假设给机器 t 分钟能完成的工作量随 t 不减，那么“t 分钟够不够”也会从 false 变成 true。
因此可以二分最小可行时间，但必须先写出正确的判定函数，并给出包含答案的上下界。
“答案是整数”本身不能推出能二分；没有单调性时，丢弃半边就没有依据。
本章程序先只实现数组查找，二分答案留作迁移练习。

## 完整 C++17 例题程序

独立源文件：[06-binary-search.cpp](../examples/06-binary-search.cpp)。输入输出约定见本章题目；程序针对题目保证的合法输入。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int first_at_least(const vector<long long> &a, long long x) {
    int l = 0, r = static_cast<int>(a.size());
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] >= x) r = mid;
        else l = mid + 1;
    }
    return l;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    if (!(cin >> n >> q)) return 0;
    vector<long long> a(n);
    for (auto &v : a) cin >> v;
    while (q--) {
        long long x;
        cin >> x;
        cout << first_at_least(a, x) << '\n';
    }
}
```

### 样例输入

```text
4 4
1 2 2 5
2
3
6
0
```

### 样例输出

```text
1
3
4
0
```

## 分层练习：先独立做，再展开答案

1. 对 `[2,2,2]` 查询 1、2、3，分别返回什么？
2. 如何改为寻找第一个 >x 的位置？
3. 一台机器每分钟做 3 件，另一台每分钟做 5 件，两台同时连续工作，只考虑非负整数分钟。求完成至少 31 件的最小分钟数，写出单调判定。

<details>
<summary>参考答案与思路（先尝试再看）</summary>

1. 0、0、3。最后一个 3 是越过末尾的分界下标，不是可访问元素。
2. 把判断改为 `a[mid] > x`，其余区间维护不变。
3. 判定 `8*t>=31`，t 增大后不会从可行变不可行；最小 t=4。可取 [0,31] 包含答案。本例可直接用上取整，练习重点是说清二分依据。

</details>
