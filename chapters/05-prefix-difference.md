# 第 05 章 · 前缀和与差分：复用区间里的重复工作

## 1. 题目与操作顺序

输入 n、m、q，以及 n 个数。接着 m 行 `l r v`，表示将闭区间 [l,r] 每个数增加 v。
全部修改结束后，再处理 q 行 `l r`，输出最终数组在该区间的和。
1≤n≤200000，0≤m,q≤200000，下标从 1 开始，所有区间合法；初值和增量绝对值≤10^6。
“全部修改之后才查询”是重要条件。本程序不支持任意交错的修改与查询。

## 2. 先解决重复求和：前缀和

如果每次从 l 加到 r，会反复计算大量重叠部分。
定义 s[i] 为前 i 个数的和，s[0]=0：`s[i]=s[i-1]+a[i]`。
区间 [l,r] 的和是 `s[r]-s[l-1]`，因为减掉的是从 1 到 l-1 的共同前缀。
这里 s[0] 不是随便填的特殊值，而是“前 0 个数之和”，让 l=1 也能使用同一公式。

## 3. 再解决重复修改：差分

定义 d[i]=a[i]-a[i-1]，其中 a[0]=0。它记录相邻位置的变化，而不是当前位置的值。
把 [l,r] 都加 v，区间内部相邻两项一起变大，差值不变；只有进入区间处增加 v，离开区间处减少 v。
所以只需 `d[l]+=v`、`d[r+1]-=v`。
对 d 做一次前缀累加，就能还原最终数组。这是望远镜求和：中间的正负项互相抵消。

## 4. 把两个过程串起来

初始 a 为 `[2,1,3,4]`，给 [2,3] 加 5：

| 位置 i | 1 | 2 | 3 | 4 |
|---|---:|---:|---:|---:|
| 原 a | 2 | 1 | 3 | 4 |
| 原 d | 2 | -1 | 2 | 1 |
| 修改后 d | 2 | 4 | 2 | -4 |
| d 的前缀，即最终 a | 2 | 6 | 8 | 4 |
| 最终 a 的前缀 s | 2 | 8 | 16 | 20 |

查询 [2,4]：s[4]-s[1]=20-2=18。
程序里的 current 是“当前还原出的 a[i]”，prefix[i] 则是“最终数组前 i 项总和”，两者不要混淆。

## 5. 正确性与代价

每次区间更新在差分中只改变两个边界；线性叠加后，对差分求前缀仍恰好得到所有更新后的数组。
再用前缀和相减，恰好保留查询区间的项。
建立差分 O(n)，每次修改 O(1)，还原与建立前缀 O(n)，每次查询 O(1)，总时间 O(n+m+q)、空间 O(n)。

## 6. 边界与方法选择

数组需要给 n+1 位置留空间，因为 r=n 时仍要写 d[r+1]；它是结束标记，不是待查询的元素。
负数不影响前缀和、差分的正确性；它们依靠加减抵消，不依靠大小单调。
在给定约束下，总和数量级可达约 4×10^16，因此使用 long long。
若修改、查询必须交错执行，不能每次都重新还原；第 15 章讨论支持动态维护的数据结构。

## 完整 C++17 例题程序

独立源文件：[05-prefix-difference.cpp](../examples/05-prefix-difference.cpp)。输入输出约定见本章题目；程序针对题目保证的合法输入。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, q;
    if (!(cin >> n >> m >> q)) return 0;
    vector<long long> diff(n + 2, 0), prefix(n + 1, 0);
    long long previous = 0;
    for (int i = 1; i <= n; ++i) {
        long long x;
        cin >> x;
        diff[i] = x - previous;
        previous = x;
    }
    for (int i = 0; i < m; ++i) {
        int l, r;
        long long v;
        cin >> l >> r >> v;
        diff[l] += v;
        diff[r + 1] -= v;
    }
    long long current = 0;
    for (int i = 1; i <= n; ++i) {
        current += diff[i];
        prefix[i] = prefix[i - 1] + current;
    }
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << prefix[r] - prefix[l - 1] << '\n';
    }
}
```

### 样例输入

```text
4 1 2
2 1 3 4
2 3 5
2 4
1 1
```

### 样例输出

```text
18
2
```

## 分层练习：先独立做，再展开答案

1. `[3,-1,2]` 的前缀和（含 s[0]）是什么？[2,3] 的和是多少？
2. 对 `[0,0,0]` 先给 [1,3] 加 2，再给 [2,2] 加 -5，最终数组是什么？
3. 如果把 `diff[r+1]-=v` 错写成 `diff[r]-=v`，用单点区间解释会发生什么。

<details>
<summary>参考答案与思路（先尝试再看）</summary>

1. `[0,3,2,4]`；4-3=1。
2. `[2,-3,2]`。两次更新可以在差分里叠加后统一还原。
3. 当 l=r 时两次修改落在同一位置并抵消，导致单点没有被修改。结束标记必须放在区间外的下一位置。

</details>
