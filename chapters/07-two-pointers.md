# 第 07 章 · 双指针：利用有序性批量排除候选

[返回目录](../README.md) · [上一章](06-binary-search.md) · [下一章](08-recursion-dfs.md)

**先修知识：** 第 02、04、06 章。

**本章完成后：** 将两数之和计数从 O(n²) 改为 O(n log n)，并正确处理重复值。

**建议学习方式：** 分两次完成。第一次读推导并手算，第二次盖住代码独立实现、做题和复盘。复杂章节可增加课次，不必一次读完。

## 1. 回到熟悉的题，但扩大数据

输入 n、target 和 n 个整数，统计 i<j 且 a[i]+a[j]=target 的位置对。
0≤n≤200000，数值和 target 的绝对值≤10^9。输出配对数量。
第 02 章的枚举在小数据上正确，但检查约 200 亿对不可取。我们需要少检查，而不只是把循环写短。

## 2. 排序之后，一次比较能知道更多

先把数组从小到大排序，令 l 指向最小值，r 指向最大值。
若 a[l]+a[r]<target，那么 a[l] 与剩余任何数相加都不够大，因为 a[r] 已经最大；所以可以安全丢弃 l。
若和>target，那么 a[r] 与剩余任何数相加都太大，因为 a[l] 已经最小；所以可以安全丢弃 r。
这说明指针移动不是猜测，而是有证据地排除一整批候选。

排序改变位置，却没有合并或删除任何元素。它只是重新排列这些“元素实例”，实例之间的无序配对数量不变。
因此计数可以排序；如果题目要求输出原下标，就必须额外保存原下标。

## 3. 相等时不能只加一

对于 `[2,2,3,3]`、target=5，左端两个 2，右端两个 3。
每个 2 都能与每个 3 配对，因此一次应加 `2×2=4`，然后整组移走。
若左右值相同，例如 `[2,2,2,2]`、target=4，那么中间所有值也都相同，应加 `4×3/2=6`。
不能用左右组数量相乘处理后一种情况，因为它们其实是同一组元素。

## 4. 看一段完整指针轨迹

数组 `[1,2,2,3,3,8]`，target=5：

| l 指向 | r 指向 | 和 | 动作 |
|---:|---:|---:|---|
| 1 | 8 | 9 | 8 与任何剩余数都太大，r 左移 |
| 1 | 3 | 4 | 1 与任何剩余数都不够，l 右移 |
| 2 | 3 | 5 | 两个 2 × 两个 3，答案加 4 |

剩余范围为空，结束。循环必须要求 l<r，不能让一个位置和自己配对。

## 5. 正确性、复杂度与适用条件

每次移动都排除不可能参加有效配对的端点；每次命中就完整统计当前两端数值的全部配对，然后删除这两组。
不同步骤统计的元素组不同，所以没有重复；剩下的所有候选始终在 [l,r]，所以没有漏掉。
排序 O(n log n)，之后两个指针各只向内走，扫描 O(n)，存储 O(n)。
即使有负数，排序后的大小推理仍成立。
不要把本结论误套到所有滑动窗口题：例如“窗口和超限就缩左端”的常见方法通常依赖非负数，允许负数后，扩张与收缩可能不再单调。

## 完整 C++17 例题程序

独立源文件：[07-two-pointers.cpp](../examples/07-two-pointers.cpp)。输入输出约定见本章题目；程序针对题目保证的合法输入。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long target;
    if (!(cin >> n >> target)) return 0;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;
    sort(a.begin(), a.end());
    int l = 0, r = n - 1;
    long long ans = 0;
    while (l < r) {
        long long sum = a[l] + a[r];
        if (sum < target) ++l;
        else if (sum > target) --r;
        else if (a[l] == a[r]) {
            long long count = r - l + 1;
            ans += count * (count - 1) / 2;
            break;
        } else {
            long long left_value = a[l], right_value = a[r];
            long long left_count = 0, right_count = 0;
            while (l <= r && a[l] == left_value) {
                ++l;
                ++left_count;
            }
            while (l <= r && a[r] == right_value) {
                --r;
                ++right_count;
            }
            ans += left_count * right_count;
        }
    }
    cout << ans << '\n';
}
```

### 样例输入

```text
6 5
1 2 2 3 3 8
```

### 样例输出

```text
4
```
