## 1. 综合例题：预算内最多完成多少项任务

有 n 项独立任务，第 i 项花费 cost[i]。每项最多选择一次，每完成一项所得收益相同。
有 q 次独立询问，给定预算 B，最多能完成多少项？不同询问不消耗彼此的任务和预算。
输入 n、q，接着 n 个花费，再给出 q 个预算；0≤n,q≤200000，0≤cost[i]≤10^9，0≤B≤10^18。
输出每次询问的最大任务数。

## 2. 逐句检查建模条件

“独立”表示没有前置依赖，不需要第 12 章拓扑排序。
“收益相同”意味着目标只是数量，优先选便宜任务才有依据；如果价值不同，就可能变成背包。
“询问独立”意味着一份排序和前缀和可复用；若任务会被买走，则静态预处理不够。
“花费非负”保证前缀和单调，让二分成立；零花费允许前缀和重复。
先识别这些条件，再决定算法，而不是看到“预算”就立即套背包。

## 3. 第一步：证明选 k 项的最低花费

把花费排序为 c[0]≤c[1]≤...。
任意选 k 项，若漏了前 k 个中的便宜项，却选了后面的贵项，可以交换，花费不增加。
反复交换，得到前 k 个。因此选 k 项的最低花费就是最便宜 k 项的和。
这一步将“枚举所有任务组合”变成“只需决定数量 k”。

## 4. 第二步：用前缀和表达每个数量的代价

定义 s[0]=0，s[k] 为最便宜 k 项的总花费。
预算 B 能完成 k 项，当且仅当 s[k]≤B。
由于花费非负，s 非递减，可行数量从 0 开始连续，到某个位置后全部不可行。
于是用 upper_bound 找第一个 >B 的前缀位置，前一位置就是最大可行数量。

## 5. 手算，尤其检查免费任务

原花费 `[4,0,3,2]`，排序为 `[0,2,3,4]`，s 为 `[0,0,2,5,9]`。

| 预算 B | 第一个 >B 的前缀下标 | 最大任务数 |
|---:|---:|---:|
| 0 | 2 | 1 |
| 4 | 3 | 2 |
| 5 | 4 | 3 |
| 100 | 5（end） | 4 |

预算为 0 仍可做一项免费任务。这里不能用 lower_bound 后直接减 1，因为遇到相等预算和重复前缀时会停得太早。
n=0 时 s 只有一个 0；非负预算的 upper_bound 为 end，减 1 后正确得到 0。

## 6. 完整代价与程序验证

排序 O(n log n)，前缀和 O(n)，每次查询 O(log(n+1))，总空间 O(n)。
先用下面的完整程序理解流程，再盖住答案独立实现。
小规模验证时可以枚举所有子集，找预算内最大的子集大小；它与排序贪心走不同思路，适合当独立对照。
常见错误包括把同一次询问中的预算消耗延续到下一次、把费用去重、漏掉 s[0]、使用 int 保存总费用。

## 7. 一套可以反复使用的解题顺序

1. 用自己的话写出已知、所求、约束和输出格式，特别标出“至多/恰好”“严格/非严格”“有向/无向”。
2. 写一个一定正确的朴素想法，计算它在最大输入下的规模。
3. 找到浪费：重复求和、重复搜索、无效候选，还是不需要保留的历史信息？
4. 给改进方法写一句不变量或状态定义，再解释为什么不漏解。
5. 先手算小例子，再编码，至少测试最小规模、重复值、无解和数值边界。
6. 小数据对拍，失败后缩小到最短反例；记录原因，不只记录修改了哪一行。

一次练习结束后应能回答：我的方法依靠什么条件？拿掉这个条件会怎样？
这比“我记得这个模板”更能说明已经掌握。

## 完整 C++17 例题程序

独立源文件：[18-integration.cpp](../examples/18-integration.cpp)。输入输出约定见本章题目；程序针对题目保证的合法输入。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    if (!(cin >> n >> q)) return 0;
    vector<long long> cost(n);
    for (auto &x : cost) cin >> x;
    sort(cost.begin(), cost.end());
    vector<long long> prefix(n + 1, 0);
    for (int i = 0; i < n; ++i) prefix[i + 1] = prefix[i] + cost[i];
    while (q--) {
        long long budget;
        cin >> budget;
        auto it = upper_bound(prefix.begin(), prefix.end(), budget);
        int answer = static_cast<int>(it - prefix.begin()) - 1;
        cout << answer << '\n';
    }
}
```

### 样例输入

```text
4 4
4 0 3 2
0
4
5
100
```

### 样例输出

```text
1
2
3
4
```
