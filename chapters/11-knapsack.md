# 第 11 章 · 0/1 背包：同一个物品为什么不能重复拿

## 1. 已知、限制与目标

有 n 件物品，第 i 件重量 w_i、价值 v_i，每件最多取一次。背包容量 W，求重量不超过 W 的最大总价值。
输入 n、W，接着 n 行重量和价值。0≤n≤200，0≤W≤20000，1≤w_i≤20000，0≤v_i≤10^9。
可以什么都不拿；不是必须恰好装满。

## 2. 为什么不能只按性价比拿

容量为 4，物品为 (重量3,价值5)、(重量2,价值3)、(重量2,价值3)。
先拿性价比最高的第一件只能得到 5，而后两件合计价值 6。
0/1 选择之间存在容量配合关系，局部最优不一定组成全局最优。
第 08 章可以枚举选或不选，但 n=200 时 2^n 不可行，需要合并等价子问题。

## 3. 从二维状态开始理解

定义 f[i][c]：只考虑前 i 件物品，总重量不超过 c 时的最大价值。
第 i 件不拿，得到 f[i-1][c]；拿它，则必须 c≥w_i，得到 f[i-1][c-w_i]+v_i。
两种情况互斥且覆盖所有方案，取最大值即可。
初值 f[0][c]=0，因为没有物品时可以选空集。答案 f[n][W]。

## 4. 手算两件物品

容量 4，先处理 (2,3)，再处理 (3,4)：

| 已考虑的物品 | c=0 | 1 | 2 | 3 | 4 |
|---|---:|---:|---:|---:|---:|
| 无 | 0 | 0 | 0 | 0 | 0 |
| (2,3) | 0 | 0 | 3 | 3 | 3 |
| 再加 (3,4) | 0 | 0 | 3 | 4 | 4 |

两件重量合计 5，不能同时放入容量 4，所以答案是 4。
这张表应先会自己填，再考虑省空间。

## 5. 压成一维后，旧行容易被覆盖

转移只需要上一行，因此用 dp[c] 保存当前一行。
更新第 i 件时，右侧 dp[c-w_i] 必须仍代表“还没处理第 i 件”的状态。
从大容量往小容量更新时，c-w_i<c，这个更小位置还没被本件物品更新，因此读取的是旧行。

反过来，若从小到大，只有一件 (2,3)、容量 4：先令 dp[2]=3，再令 dp[4]=dp[2]+3=6，就把同一件物品拿了两次。
这正是完全背包允许重复取时会利用的关系；循环方向对应的是不同模型，不是格式习惯。

## 6. 初值与复杂度的含义

时间 O(nW)，空间 O(W)。这里 W 是容量的数值，W 特别大时不能只看 n 小就认为能做。
本题“至多容量”且允许空集，所以所有 dp 初始为 0。
若题目要求“恰好装满”，应只有 dp[0]=0，其他容量标记为不可达，转移前检查来源是否可达，否则会把不存在的方案当作合法。

## 完整 C++17 例题程序

独立源文件：[11-knapsack.cpp](../examples/11-knapsack.cpp)。输入输出约定见本章题目；程序针对题目保证的合法输入。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, capacity;
    if (!(cin >> n >> capacity)) return 0;
    vector<long long> dp(capacity + 1, 0);
    for (int i = 0; i < n; ++i) {
        int weight;
        long long value;
        cin >> weight >> value;
        for (int c = capacity; c >= weight; --c) {
            dp[c] = max(dp[c], dp[c - weight] + value);
        }
    }
    cout << dp[capacity] << '\n';
}
```

### 样例输入

```text
3 4
3 5
2 3
2 3
```

### 样例输出

```text
6
```

## 分层练习：先独立做，再展开答案

1. 只有物品 (2,3)，容量 4，倒序与正序各得到什么？
2. 容量为 0、或者所有物品都超重，答案为何都是 0？
3. 要求恰好装满容量 3，只有物品 (2,5)，应如何表示最终结果？

<details>
<summary>参考答案与思路（先尝试再看）</summary>

1. 倒序为 3，正序为 6；后者重复使用同一件物品，解的是另一种模型。
2. 空集合法，价值为 0；没有任何物品能够进入背包。
3. 应报告不可达，而不是价值 5。初始化 dp[1..3] 为负无穷或另设可达数组，只有可达来源才可转移，最后检查 dp[3]。
