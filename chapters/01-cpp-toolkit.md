**先修知识：** 会变量、if 和 for；不要求熟悉 STL。

**本章完成后：** 独立读入一个数组，统计总和、最大值和最大值出现次数。

**建议学习方式：** 分两次完成。第一次读推导并手算，第二次盖住代码独立实现、做题和复盘。复杂章节可增加课次，不必一次读完。

## 1. 先把题目翻译成程序要做的事

给出 n 个整数，输出总和、最大值、最大值出现次数。三个结果之间用空格隔开。
输入第一行 n，第二行 n 个整数；1 ≤ n ≤ 200000，每个整数的绝对值不超过 10^9。

已知是“一批数据”，所求是“三项统计”。数组负责保存数据，循环负责逐个观察，变量负责记住已经得到的结果。
这条信息流是：输入 → 保存 → 遍历 → 更新统计量 → 输出。

## 2. 从 C 数组走到 vector

`vector<long long> a(n);` 表示创建一个长度为 n 的动态数组，每个元素是 long long。
它的合法下标仍是 0 到 n-1，`a[i]` 和 C 数组的访问方式一样。
`vector` 会管理内存，但 `a[n]` 仍然越界；“动态”不意味着任意下标都能用。

`cin >> n` 从标准输入读数据，`cout << ans` 输出结果。
开头的两行快速输入设置用于减少 C++ 流的额外开销；采用后，本课程不混用 scanf/printf。
`using namespace std;` 让我们可以写 vector 而不用每次写 std::vector。

为什么总和用 long long？最坏情况下 200000 × 10^9 = 2×10^14，通常的 32 位 int 存不下。
变量类型应由结果的范围决定，不能只看单个输入的范围。乘法也类似：两个 int 先相乘可能已经溢出，再赋给 long long 也来不及；需要先提升操作数，例如 `1LL * x * y`。

## 3. 用一个小数组手算状态

对 `[-3, 7, 7, 2]`，先设 sum=0，mx=a[0]=-3，cnt=0，然后从第一个数开始扫描：

| 读到的数 | sum | mx | cnt | 原因 |
|---|---:|---:|---:|---|
| -3 | -3 | -3 | 1 | 等于当前最大值 |
| 7 | 4 | 7 | 1 | 出现新最大值，旧计数失效 |
| 7 | 11 | 7 | 2 | 再次遇到当前最大值 |
| 2 | 13 | 7 | 2 | 不改变最大值统计 |

这里的不变量是：处理完前 k 个数，三个变量恰好描述这 k 个数的统计结果。
每读一个新数只修改它会影响的统计量，因此扫描结束时，不变量就变成了整道题的答案。

## 4. 理解关键语句

`for (long long x : a)` 是范围 for，表示依次取出 a 中的元素，复制给 x。
本例只读数据，因此复制没问题。若想通过循环修改原数组，应使用引用，例如 `for (long long &x : a)`。
`&` 在这里让 x 成为原元素的别名。

发现 `x > mx` 时，必须同时做 `mx=x` 和 `cnt=1`；最大值变了，计数的对象也变了。
用 `else if` 保证这一个数不会在设为 1 后又被多加一次。

## 5. 代价、条件与易错点

两次线性遍历，时间 O(n)；保存数组占 O(n) 空间。若不需要保留数组，可以边读边统计，将额外空间降到 O(1)。
本题 n≥1，所以 a[0] 存在。最大值不能初始化为 0，否则全负数输入会错。
不要用运行结果“刚好正确”代替边界检查：单元素、全相同、全负数都应能解释。

## 完整 C++17 例题程序

独立源文件：[01-cpp-toolkit.cpp](../examples/01-cpp-toolkit.cpp)。输入输出约定见本章题目；程序针对题目保证的合法输入。

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n)) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    long long sum = 0, mx = a[0];
    int cnt = 0;
    for (long long x : a) {
        sum += x;
        if (x > mx) {
            mx = x;
            cnt = 1;  // 新最大值取代旧最大值
        } else if (x == mx) {
            ++cnt;
        }
    }
    cout << sum << ' ' << mx << ' ' << cnt << '\n';
}
```

### 样例输入

```text
4
-3 7 7 2
```

### 样例输出

```text
13 7 2
```

3. 不保存 vector，边读边统计三个结果。画出读入第一个数前后的变量变化。

<summary>参考答案与思路（先尝试再看）</summary>

1. `-9 -2 2`。最大值是 -2，出现两次。
2. 用第一个元素初始化 mn，每轮令 mn 为 mn 与 x 中较小的一个；不能初始化为 0，因为全正数时会错。
3. 先单独读第一个数，设 sum=mx=x、cnt=1，再读剩下 n-1 个数。这样不访问空数组，也不需要人为选一个“足够小”的初始最大值。
