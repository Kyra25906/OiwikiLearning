## 1. 把机器人规则读清楚

机器人起点为 (0,0)，面向北。输入一个非空指令串，仅含 L、R、F，长度不超过 200000。
L 表示原地左转 90 度，R 表示原地右转 90 度，F 表示沿当前朝向前进一步。
规定向东 x 增加、向北 y 增加。输出最终 x、y、朝向字母 N/E/S/W。

已知是初始状态和一串操作，所求是所有操作执行后的状态。
位置和方向都影响未来，所以状态必须包含 `(x,y,dir)`，不能只保存位置。

## 2. 把四个方向排成环

按顺时针顺序编号：北 0、东 1、南 2、西 3。
向右转相当于编号加 1，再对 4 取模：`(dir+1)%4`。
向左转相当于加 3 再取模：`(dir+3)%4`。
不直接写 `(dir-1)%4`，因为 C++ 的负数余数可能为负，不能拿来当数组下标。

把每个方向的一步变化放进两个数组：

| dir | 方向 | dx | dy |
|---:|---|---:|---:|
| 0 | N | 0 | 1 |
| 1 | E | 1 | 0 |
| 2 | S | 0 | -1 |
| 3 | W | -1 | 0 |

F 就统一写成 `x+=dx[dir]`、`y+=dy[dir]`，省去四份容易写错的分支。

## 3. 手算一次完整执行

指令 `FFRFLF`：

| 操作后 | x | y | 方向 |
|---|---:|---:|---|
| 初始 | 0 | 0 | N |
| F | 0 | 1 | N |
| F | 0 | 2 | N |
| R | 0 | 2 | E |
| F | 1 | 2 | E |
| L | 1 | 2 | N |
| F | 1 | 3 | N |

转向不会移动，前进不会转向。这两个规则分开后，检查每一步就很直接。
不变量是：处理完前 k 个字符，三个变量恰好等于机器人执行这 k 条指令后的状态。
初始正确，每种操作又按定义保持正确，因而最终输出正确。

## 4. 从本题迁移到复杂模拟

遇到多角色、多个时间点的模拟，先列“状态表”和“事件顺序表”。
例如先移动再攻击与先攻击再移动可能产生不同结果，不能自行交换题目规定的顺序。
有“同时发生”的规则时，往往要先根据旧状态计算全部结果，再统一更新，避免前一个更新污染后一个计算。
本题的指令顺序是串行的，所以可以读一条、立即更新一条。

## 5. 代价与边界

长度为 m 的指令串，每个字符只处理一次，时间 O(m)。存储指令串占 O(m)，状态本身只占 O(1)。
测试应包含纯转向、四次同向转向、向西或向南移动，而不只是一直向北。

## 完整 C++17 例题程序

独立源文件：[03-simulation.cpp](../examples/03-simulation.cpp)。输入输出约定见本章题目；程序针对题目保证的合法输入。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string commands;
    if (!(cin >> commands)) return 0;
    const int dx[4] = {0, 1, 0, -1};
    const int dy[4] = {1, 0, -1, 0};
    const string names = "NESW";
    int x = 0, y = 0, dir = 0;
    for (char c : commands) {
        if (c == 'L') dir = (dir + 3) % 4;
        else if (c == 'R') dir = (dir + 1) % 4;
        else {
            x += dx[dir];
            y += dy[dir];
        }
    }
    cout << x << ' ' << y << ' ' << names[dir] << '\n';
}
```

### 样例输入

```text
FFRFLF
```

### 样例输出

```text
1 3 N
```

## 分层练习：先独立做，再展开答案

1. 手算 `LFF` 与 `RRRR` 的输出。
2. 增加 B 指令：后退一步，但不改变朝向。写出状态更新式。
3. 给平面增加边界 `0≤x,y≤2`，越界前进应原地不动。应该在更新前还是更新后检查？

<details>
<summary>参考答案与思路（先尝试再看）</summary>

1. 分别为 `-2 0 W` 和 `0 0 N`。
2. `x-=dx[dir]; y-=dy[dir];`。不能把 dir 加 2 后忘记恢复，因为后退不是转身。
3. 先计算候选位置 nx、ny，合法才赋给 x、y。先改再撤销也能实现，但更容易漏撤销一个字段。

</details>
