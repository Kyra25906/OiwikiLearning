# 第 10 章 · 动态规划入门：用状态保存已经解决的子问题

**先修知识：** 第 02、08 章；会数组。

**本章完成后：** 从枚举前驱推导最长严格递增子序列的状态、转移和顺序。

**建议学习方式：** 分两次完成。第一次读推导并手算，第二次盖住代码独立实现、做题和复盘。复杂章节可增加课次，不必一次读完。

## 1. 先区分子序列与连续子数组

给出 n 个整数，求最长严格递增子序列的长度。子序列可以跳过元素，但不能改变先后顺序。
输入 n 和 n 个整数，0≤n≤3000，数值绝对值≤10^9。空数组答案为 0。
例如 `[3,1,2,5,4]` 可以选 `[1,2,5]`，也可以选 `[1,2,4]`，长度都是 3。
严格递增要求相邻选中值满足 `<`，相等不能接上。

## 2. 暴力搜索在哪里重复

枚举所有子集后检查是否递增，会产生约 2^n 个选择。
但许多不同的选择最终结束在同一个位置。若我们只想继续往后接元素，过去具体选了哪些数往往不再重要：能否接上由结尾值决定，已有优势由长度决定。
于是把相同结尾的方案归为一类，只保留最长的那个。

## 3. 一句话定义状态

定义 `dp[i]` 为“必须以 a[i] 结尾的最长严格递增子序列长度”。
“必须以 i 结尾”不能省略，否则无法用 a[j]<a[i] 判断能否转移。
若前一个选中位置是 j，那么必须 j<i 且 a[j]<a[i]，可得到长度 dp[j]+1。
所以从 dp[i]=1 起步，枚举所有合法 j，取最大值。1 对应只选 a[i] 自己。
最终答案是所有 dp[i] 的最大值，不一定是 dp[n-1]。

## 4. 用表格走完状态变化

对 `[3,1,2,5,4]`：

| i | a[i] | 合法前驱值 | dp[i] |
|---:|---:|---|---:|
| 0 | 3 | 无 | 1 |
| 1 | 1 | 无 | 1 |
| 2 | 2 | 1 | 2 |
| 3 | 5 | 3、1、2 | 3 |
| 4 | 4 | 3、1、2 | 3 |

例如计算 5 时，从结尾为 2 的最优方案 `[1,2]` 接上 5，得到长度 3。
结尾为 2 的较短方案 `[2]` 没有保留价值：它能接的后续元素，较长方案也都能接。

## 5. 为什么转移完整又正确

任意以 i 结尾的递增子序列，要么只有 a[i]，要么存在唯一的倒数第二个位置 j。
我们枚举了所有合法 j，所以不会漏掉最优方案。
把 j 结尾的方案替换成 dp[j] 对应的更长方案，仍可接 a[i]，因此只保留 dp[j] 足够。
计算 i 时只依赖更小的 j，按 i 从小到大处理便保证所需状态已经算好。

## 6. 用四个问题检查任何 DP

状态到底表示什么？答案从哪些更小状态来？最小状态怎么初始化？按什么顺序才不会读到没算好的值？
这四个问题比记忆某条递推式更重要。本章时间 O(n²)，数组与 dp 占 O(n) 空间。
后续可以用“每种长度的最小结尾值”加二分优化到 O(n log n)，但那是另一个状态定义；不能直接把本章内层 for 随意改成二分。

## 完整 C++17 例题程序

独立源文件：[10-dp-basics.cpp](../examples/10-dp-basics.cpp)。输入输出约定见本章题目；程序针对题目保证的合法输入。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n)) return 0;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;
    vector<int> dp(n, 1);
    int answer = 0;
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < i; ++j) {
            if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
        }
        answer = max(answer, dp[i]);
    }
    cout << answer << '\n';
}
```

### 样例输入

```text
5
3 1 2 5 4
```

### 样例输出

```text
3
```

## 分层练习：先独立做，再展开答案

1. `[2,2,2]` 的严格递增答案是多少？改成非递减会是多少？
2. 给出一个最终答案不等于 dp[n-1] 的数组。
3. 如何输出具体的最长子序列，而不仅是长度？

<details>
<summary>参考答案与思路（先尝试再看）</summary>

1. 严格递增为 1；非递减为 3，转移条件从 `<` 改为 `<=`。
2. `[1,2,3,0]`：dp 为 `[1,2,3,1]`，答案 3，但最后一个状态为 1。
3. 每次严格改进 dp[i] 时记录 pre[i]=j，初始化 pre 为 -1。找到最大 dp 的结尾位置，沿 pre 回溯，再反转，就得到一条最优子序列。

</details>
